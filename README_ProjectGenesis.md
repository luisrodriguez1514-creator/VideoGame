# Project Genesis (UE 5.7)

Este repositorio contiene una plantilla mínima de proyecto **Blueprint-only** para UE 5.7.

## Cómo abrir
1. Abre Unreal Engine 5.7.
2. Usa **File → Open Project** y selecciona `ProjectGenesis.uproject`.
3. UE generará los archivos intermedios al abrirlo.

## Carpetas base
Se incluyen carpetas vacías para iniciar Blueprints y datos:
- `Content/Blueprints/Player`
- `Content/Blueprints/World`
- `Content/Blueprints/Items`
- `Content/Blueprints/UI`
- `Content/Data/Items`
- `Content/Data/Recipes`
- `Content/Materials`
- `Content/Meshes`
- `Content/Animations`

## Siguientes pasos
Crear en el editor:
- Blueprint de Player y GameMode.
- Blueprint de World/Chunk y sistema de generación procedural.
- DataAssets o DataTables para ítems y recetas.
