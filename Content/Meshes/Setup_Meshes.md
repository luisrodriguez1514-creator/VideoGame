# Setup de Meshes

Objetivo: definir los meshes básicos para el prototipo.

## 1) Meshes de voxel
- Usar `SM_Cube` como placeholder (UE5 Starter).
- Si se requiere, crear `SM_VoxelBlock` (cube con pivote centrado).

## 2) Meshes de herramientas
- Placeholders simples: `SM_Axe`, `SM_Pickaxe`, `SM_Shovel`, `SM_Sword`.

## 3) Meshes de recursos
- `SM_Log` (tronco)
- `SM_StoneChunk` (roca)
- `SM_CoalChunk`

## 4) Árbol básico
- `SM_Tree_Trunk`
- `SM_Tree_Leaves`

> Nota: en prototipo se puede usar una combinación de cubos con materiales.
