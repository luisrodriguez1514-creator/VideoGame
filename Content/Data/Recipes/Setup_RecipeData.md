# Setup de Data: Recetas

Objetivo: definir recetas iniciales de crafteo.

## 1) Struct
Crear un `Struct` **S_Recipe** con:
- `RecipeId` (Name)
- `InputItems` (Array de ItemId)
- `OutputItem` (ItemId)
- `OutputQuantity` (int)

## 2) DataTable
**Ruta sugerida:** `Content/Data/Recipes/DT_Recipes`

### Recetas sugeridas
- `Craft_Axe`: Wood x2 + Stone x5 -> Axe
- `Craft_Pickaxe`: Wood x2 + Stone x6 -> Pickaxe
- `Craft_Shovel`: Wood x2 + Stone x3 -> Shovel
- `Craft_Sword`: Wood x1 + Stone x7 -> Sword
